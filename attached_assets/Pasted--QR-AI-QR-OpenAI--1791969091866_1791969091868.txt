# 내 방식 QR — 홈 화면 AI 추천 노출 및 추천 결과 화면 개선

현재 프로젝트는 중앙 **내 방식 QR** 홈페이지입니다.

이번 작업은 기존에 구현된 OpenAI 기반 맞춤 설정 추천 기능의 **홈 화면 진입 위치와 추천 결과 표시 흐름을 개선하는 작업**입니다.

현재 정상적으로 동작하는 AI 추천 API, QR v3 설정, 프로필 생성·저장·관리 기능은 유지하세요.

## 1. 홈페이지 상단에 AI 추천받기 추가

현재 첫 화면 상단에는 다음 버튼이 있습니다.

- 내 설정 살펴보기
- 내 QR 보기

하지만 AI 추천받기는 화면 아래쪽에 있어서 작은 모바일 화면에서는 스크롤해야 발견할 수 있습니다.

사용자가 홈페이지에 들어오자마자 AI 추천 기능을 발견하도록 개선하세요.

### 배치 요구사항

- 기존 상단의 '내 설정 살펴보기', '내 QR 보기' 근처에 **'AI 추천받기'** 버튼을 추가합니다.
- 가장 추천하는 배치는 기존 두 버튼 바로 아래에 AI 추천받기를 배치하는 방식입니다.
- 단, 모바일 화면에서 AI 추천받기가 첫 화면에 보이도록 전체 상단 여백과 구성 요소를 적절히 조정하세요.
- AI 추천받기가 다른 버튼보다 묻히지 않게 강조합니다.
- 기존 '내 설정 살펴보기'와 '내 QR 보기' 버튼도 유지합니다.
- AI 추천받기 버튼을 누르면 기존 AI 질문 화면으로 이동합니다.
- 페이지 아래쪽에 이미 구현된 '나에게 편한 방법을 찾아볼까요?' 섹션은 유지해도 됩니다.

특히 모바일 320px, 360px, 390px에서 페이지 진입 직후 AI 추천받기 버튼이 보이는지 확인하세요.

페이지를 불필요하게 길게 만들거나 기존 디자인을 전면 변경하지 마세요.

## 2. 사용 방법 1번 설명 변경

현재 사용 방법의 첫 단계는 '내게 맞게 고르기'입니다.

제목은 그대로 유지하고, 설명을 다음과 같이 변경하세요.

**화면을 보며 직접 고르거나, AI 추천을 받아 편한 설정을 찾으세요.**

기존 2단계 'QR로 저장하기', 3단계 '다른 곳에서 열기'는 유지합니다.

## 3. AI 추천 후 결과 화면을 먼저 보여주기

현재 사용자가 질문을 선택하고 '내 설정 추천받기'를 누르면 일반 설정 편집 화면으로 이동하는 것처럼 보여, AI 추천 결과를 충분히 확인하기 어렵습니다.

이를 수정하세요.

### 원하는 동작 순서

1. 사용자가 기존 AI 질문 5개에 답합니다.
2. **'내 설정 추천받기'를 누릅니다.**
3. OpenAI API가 추천 설정과 추천 이유를 생성합니다.
4. 응답 검증이 성공하면 **추천 설정을 즉시 기존 설정 편집 상태에 자동 반영합니다.**
5. 사용자에게는 일반 설정 화면 대신 **'나에게 맞는 설정을 준비했어요' 결과 요약 화면을 먼저 보여줍니다.**
6. 사용자가 '이 설정 사용하기'를 누르면 이미 반영된 설정을 확인·수정할 수 있는 기존 설정 화면으로 이동합니다.
7. 사용자는 설정을 직접 수정한 후 기존 저장 버튼으로 최종 QR 설정을 저장합니다.

**중요: '이 설정 사용하기' 버튼을 눌러야 추천값이 적용되는 방식으로 만들지 마세요.**

추천값은 '내 설정 추천받기'를 누르고 AI 응답이 성공한 시점에 이미 기존 설정 상태에 적용되어 있어야 합니다.

다만 이때 서버 DB에 QR 프로필을 자동 저장하거나 QR을 자동 생성하지는 않습니다. 기존 저장 절차를 유지합니다.

## 4. 추천 결과 요약 화면 디자인

사용자가 AI 추천을 완료하면 다음 내용을 중심으로 구성된 결과 화면을 표시하세요.

### 제목

**나에게 맞는 설정을 준비했어요**

### 설명

**이런 점을 생각해 추천했어요.**

### 추천 이유

사용자가 선택한 어려움과 AI 분석 결과를 바탕으로 2~4개의 짧은 설명을 표시합니다.

예시:

- 작은 글씨가 불편해서 글씨를 크게 설정했어요.
- 버튼을 누르기 어렵다고 하셔서 버튼을 크게 만들었어요.
- 어려운 단어를 이해하기 쉽도록 쉬운 말 안내를 켰어요.

추천 이유는 실제 AI 응답과 적용된 설정을 바탕으로 표시해야 합니다.

사용자가 선택하지 않은 어려움을 사실처럼 단정하지 마세요.

### 안내 문구

**적용한 뒤에도 설정을 직접 바꿀 수 있어요.**

### 주요 버튼

**이 설정 사용하기**

이 버튼은 이미 자동 적용된 설정을 확인하고 수정할 수 있는 기존 설정 화면으로 이동하는 역할을 합니다.

버튼을 눌러야 AI 설정이 최초 적용되는 구조가 아닙니다.

### 보조 버튼

- **답변 다시 보기**
- **직접 설정하기**

답변 다시 보기는 기존 AI 질문 화면으로 돌아가되, 선택했던 답변을 유지합니다.

직접 설정하기는 일반 설정 화면으로 이동합니다.

이때 이미 반영된 추천값을 유지할지 사용자가 선택할 수 있도록, 불필요한 초기화나 덮어쓰기를 방지하세요.

## 5. 설정 상태 일관성 유지

AI 추천 결과가 성공적으로 생성되는 즉시 현재 편집 중인 QR 설정 상태가 추천값으로 변경되어야 합니다.

다음 동작을 검증하세요.

- AI 추천값과 실제 설정 버튼 상태 일치
- AI 추천값과 기존 미리보기 상태 일치
- 결과 화면에서 설정 확인 화면으로 이동해도 추천값 유지
- 사용자가 추천 설정을 수동 변경할 수 있음
- 사용자가 수정한 값을 AI 응답이 뒤늦게 다시 덮어쓰지 않음
- 최종 저장 시 수정된 설정값 사용
- 저장 후 QR 재조회 시 최종 설정과 일치

AI 추천 결과를 단순한 설명 텍스트로만 표시하면 안 됩니다.

AI 추천값 적용 시점은 **모델 응답 검증 성공 직후**입니다.

DB에 저장되는 시점은 **사용자가 기존 저장 버튼을 누른 후**입니다.

두 시점을 명확하게 구분하세요.

## 6. 기존 기능 유지

다음 기능은 그대로 유지합니다.

- 실제 OpenAI API 추천
- 확정된 질문 5개 및 선택지
- 복수 선택·건너뛰기
- 추천 이유 생성
- QR v3 설정값 검증
- 기존 QR 생성·조회·수정·폐기·재발급
- 기존 직접 설정 경로
- 개인정보 차단
- 큰 글씨·큰 버튼·고대비
- 쉬운 말·스마트 길잡이·음성 안내
- 하단 조작 60·70·80%
- 기존 접근성 미리보기
- 모바일 반응형 디자인

AI 모델, 기존 추천 API, 데이터베이스, QR 스키마는 불필요하게 수정하지 마세요.
