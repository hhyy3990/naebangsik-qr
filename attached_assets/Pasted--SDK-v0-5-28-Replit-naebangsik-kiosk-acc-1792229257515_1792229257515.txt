# 무인민원발급기 — SDK v0.5.28 후보 설치 및 실제 오류 검증

현재 프로젝트는 **무인민원발급기 Replit**입니다.

첨부한 `naebangsik-kiosk-accessibility-sdk-0.5.28.tgz`는 데모커피의 공통 SDK 최신 소스를 빌드한 검증용 후보입니다.

현재 설치된 v0.5.27을 v0.5.28 후보로 업데이트하고, 사용자가 실제 Production QR 테스트에서 발견한 오류를 검증해 주세요.

이번 작업은 **설치와 실제 화면 검증만** 수행합니다.

SDK 내부 소스, 무인민원발급기 업무 코드, CSS, 안내 문구는 변경하지 마세요.

## 1. SDK 설치

- 기존 v0.5.27 tarball 보존
- 첨부한 v0.5.28 설치
- package.json과 lockfile 갱신
- 실제 브라우저 런타임 버전 확인
- 타입 검사 및 프로덕션 빌드

## 2. 최우선 — 쉬운 말 66·137페이지 오류 확인

실제 무인민원발급기에서 다음 문제가 발생했습니다.

- `certificate.type-selection`: 66페이지
- `certificate.id-input`: 137페이지
- 문장이 한 글자씩 분할됨

다음 설정으로 실제 발급 화면을 열어 테스트하세요.

- 화면: 320×844, 360×667, 390×844
- 글씨 매우 크게
- 버튼 크게
- 고대비 켜기
- 쉬운 말 켜기
- 스마트 길잡이 켜기
- 하단 조작 80%

기존 호스트의 실제 안내 문구를 그대로 사용하세요.

다음을 확인합니다.

1. 실제 페이지 수
2. 한 글자씩 분할되는 현상
3. 원문 누락·중복
4. 본문·제목·이전·다음 버튼 잘림
5. 패널 상단 위치
6. 페이지를 넘길 때 위치 점프
7. 안내 패널 내부 스크롤 발생 여부

본문이나 버튼이 잘린다면 실제 픽셀 좌표와 크기를 기록하세요.

**한 글자 분할이나 잘림이 여전히 발생한다면 다른 테스트를 중단하고 재현 결과를 보고하세요. 호스트에서 우회 수정하지 마세요.**

## 3. 자동 하단 80% 적용 확인

다음 두 경우를 구분해서 검증하세요.

- `easyLanguage: true`, `viewportMode: null` → 실제 업무 화면은 하단 80%
- 명시적으로 하단 60·70·80% 선택 → 사용자의 선택 유지

원본 QR 프로필 데이터는 변경하지 마세요.

시작 화면은 SDK에서 기존대로 처리하고, 실제 업무 화면에서 자동 80%가 적용되는지 확인합니다.

## 4. 긴 스마트 길잡이 안내 확인

실제 무인민원발급기에서 긴 스마트 길잡이 문구가 아래로 잘리는 문제가 있었습니다.

- 하단 80%에서 문구 전체 표시 여부
- 패널 하단 경계 초과 여부
- 스마트 길잡이 시작 시 자동 펼침
- 안내 종료 후 기존 쉬운 말 접힘 상태 복원
- 기존 표시 대기 및 유지 시간 정상
- 화면 스크롤이나 입력 중 조기 종료 없음

**내용이 잘리는 경우 스마트 길잡이를 임의로 여러 페이지로 변경하지 마세요.**

실측값을 보고하고 사용자 승인을 기다리세요.

## 5. 기존 오류 재발 검사

다음 기능을 유지해야 합니다.

- 상단 안내 패널 위치: 하단 모드 약 8px
- 페이지 이동 시 상단 위치 점프 없음
- 스크롤 중 하단 안내 위치 점프 없음
- 스크롤 안내 기본 간격 12px
- 맨 아래에서 스크롤 안내 숨김
- QR 도크 정상 표시
- QR v1~v4 호환성
- 큰 글씨·큰 버튼·고대비 정상 적용
- 업무 버튼 클릭 가능
- 발급 완료 후 복귀 및 설정 초기화

## 6. 전체 발급 회귀

최우선 오류가 해결된 경우에만 기존 전체 발급 절차를 검증하세요.

주민등록등본 선택 → 주민등록번호 키패드 → 지문 확인 → 표시 항목 → 수수료 면제 → 발급 부수 → 신청 확인 → 결제 → 인쇄 → 완료 → 자동 초기화.

기존 18개 증명서 메뉴를 유지합니다.

개인정보 대신 가상 데이터를 사용하세요.
