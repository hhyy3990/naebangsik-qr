# 중앙 ‘내 방식 QR’ — 미리보기 상단 안내 배치 수정 및 실제 브라우저 검증

현재 프로젝트는 **중앙 ‘내 방식 QR’ Replit**입니다.

이번 작업은 QR v5 개발 이후 발견된 **체험형 미리보기의 쉬운 말 안내·스마트 길잡이 위치 오류 수정**과 **실제 브라우저 상호작용 검증**에 한정합니다.

사용자가 실제 화면에서 다음 문제를 확인했습니다.

- 미리보기 위쪽의 ‘사용하지 않는 위쪽 영역’은 비어 있음
- 쉬운 말 안내가 키오스크 조작 영역 중간에 나타남
- 스마트 길잡이도 중간에 오버레이되어 기존 쉬운 말과 조작 화면을 가림
- 아래쪽 내용 안내는 스크롤할 때 정상 표시되고, 끝까지 내리면 정상적으로 사라짐

**중요: 아래쪽 내용 안내 기능은 정상 확인됐으므로 관련 로직·위치 계산은 수정하지 마세요.**

## 1. 수정 목표

현재 미리보기의 안내 영역을 다음처럼 바꾸세요.

**쉬운 말 안내와 스마트 길잡이는 키오스크 조작 화면 위쪽의 별도 공간에 표시하고, 아래쪽에는 실제 키오스크 조작 화면을 유지해야 합니다.**

- 쉬운 말 안내가 ON이면 상단에 쉬운 말 패널 표시
- 스마트 길잡이가 등장하면 동일한 상단 안내 영역에서 쉬운 말 패널 대신 스마트 길잡이 표시
- 스마트 길잡이를 X로 닫거나 자동 종료하면 같은 상단 영역에서 기존 쉬운 말 페이지 복귀
- 쉬운 말과 스마트 길잡이가 키오스크 메뉴 버튼·스크롤 콘텐츠를 덮지 않도록 배치
- 상단의 안내 영역을 활용하기 위해 ‘사용하지 않는 위쪽 영역’이라는 문구와 빈 공간 처리 방식 수정 가능
- 실제 키오스크 조작 영역은 기존 하단 60·70·80% 설정에 따라 유지

이는 **중앙 사이트의 연습용 미리보기 UI에만 적용**하는 수정입니다.

실제 SDK의 쉬운 말·스마트 길잡이 동작이나 두 키오스크 앱은 변경하지 마세요.

## 2. 상단 안내 영역 구성

기존 `Preview` 컴포넌트와 관련 CSS를 확인하세요.

현재 쉬운 말 패널 및 스마트 길잡이가 어떤 요소를 기준으로 배치되는지 확인하고, 중간에 나타나는 원인을 먼저 파악하세요.

배치 원칙은 다음과 같습니다.

### 쉬운 말 안내 ON

- 하단 조작 화면보다 위쪽에 설명 패널을 표시
- 안내 패널은 지정된 상단 공간 안에 들어가야 함
- 패널 안의 제목·설명·이전/다음 버튼 모두 표시
- 사용자가 1/3 → 2/3 → 3/3으로 이동할 수 있어야 함
- 글씨가 잘리거나 버튼이 패널 밖으로 나가면 안 됨
- 패널이 메뉴 보기·주문 조회 등 실제 조작 버튼을 가리면 안 됨

### 스마트 길잡이 등장

- 쉬운 말 패널과 같은 상단 공간에 표시
- 기존 쉬운 말 패널 위에 겹겹이 나타나지 않도록 처리
- 스마트 길잡이의 설명과 X 버튼이 모두 보여야 함
- X 버튼은 터치·키보드로 조작 가능
- X를 누르면 기존에 읽던 쉬운 말 페이지 복귀
- 자동 종료해도 동일하게 복귀
- 같은 체험 실행에서 반복 등장하지 않음

### 쉬운 말 OFF + 스마트 길잡이 ON

- 스마트 길잡이가 독립적으로 상단 영역에 표시
- 종료 후 상단 안내 영역은 설정에 맞게 정리
- 아래 키오스크 조작 화면의 상태는 유지

## 3. 공간 부족 해결 방법

현재 미리보기는 9:16 세로형입니다.

가능하면 **9:16 비율을 유지**하면서 다음 순서로 해결하세요.

1. 상단 안내 패널의 위치를 올바르게 지정
2. 불필요한 패딩·마진·상단 빈 공간 축소
3. 안내 패널 내부의 글자 간격·여백 최적화
4. 여전히 부족할 경우 미리보기 전체 크기를 반응형으로 확대하는 방안 검토
5. 마지막 수단으로 연습용 안내 글씨 크기를 소폭 조정

**큰 글씨 설정의 의미가 사라질 정도로 글씨를 작게 줄이면 안 됩니다.**

9:16 화면 전체를 무조건 확대하면 모바일 화면에서 잘릴 수 있으니 최대 너비와 반응형 제약을 함께 확인하세요.

필요하면 상단 안내 패널 내부만 스크롤 가능하게 만들 수 있지만, 이전·다음 버튼과 X 버튼은 항상 접근 가능해야 합니다.

가능한 한 긴 안내 텍스트를 짧고 자연스러운 연습용 문장으로 정리하되, 원래 의도를 훼손하거나 이미 검증된 키오스크 안내 문구를 변경하지 마세요.

## 4. 하단 60·70·80% 및 자동 80% 유지

현재 미리보기 정책은 다음과 같습니다.

| 설정 | 하단 조작 영역 |
|---|---|
| 쉬운 말 OFF + viewportMode:null | 100% |
| 쉬운 말 ON + viewportMode:null | 자동 하단 80% |
| 명시적 하단 60% | 하단 60% |
| 명시적 하단 70% | 하단 70% |
| 명시적 하단 80% | 하단 80% |

이 정책은 변경하지 마세요.

특히 **하단 80%를 사용하더라도, 쉬운 말 안내는 위쪽의 별도 공간에 표시되어야 합니다.**

설정값 `viewportMode:null`을 실제 저장할 때 80%로 바꾸면 안 됩니다.

하단 60·70·80% 설정 변경에 따라 조작 영역의 시작 위치가 정상적으로 바뀌는지 확인하세요.

공간상 쉬운 말 안내가 상단 20%에 물리적으로 들어가지 않는다면, 단순히 아래쪽 조작 영역에 겹쳐 표시하지 말고 상단 패널의 간결화·크기 최적화 등으로 해결하세요.

해결이 불가능한 조합이 있다면 해당 설정과 화면 크기를 명확하게 보고하고 임의로 기존 화면 배치 정책을 바꾸지 마세요.

## 5. 실제 브라우저 상호작용 검증

정적 화면 확인이나 단위 테스트만으로 완료 처리하지 마세요.

Replit Preview 또는 실제 Chromium 브라우저에서 다음을 직접 조작하고 결과를 확인하세요.

### A. 쉬운 말 안내

- 쉬운 말 ON → 상단 안내 패널 표시
- 1/3 → 2/3 → 3/3 이동
- 3/3 → 2/3 → 1/3 복귀
- 첫·마지막 페이지 버튼 비활성화 정상
- 안내 패널이 메뉴 버튼을 가리지 않음
- 안내 문구와 페이지 번호 잘림 없음

### B. 스마트 길잡이

- Smart Guide ON 설정 후 10초 지연으로 등장
- 15초·20초 지연 설정도 실제 타이머 또는 fake timer로 확인
- 등장 시 쉬운 말 패널 대신 상단 공간에 표시
- X 클릭 후 기존 쉬운 말 페이지 복귀
- 같은 실행에서 다시 나타나지 않음
- 자동 종료 후 기존 쉬운 말 페이지 복귀
- 기본 2페이지 안내의 자동 전환과 총 15초 표시
- 느린 안내의 총 20초 표시
- OFF → ON 전환으로 새 체험 시작
- 별도 ‘다시 연습하기’ 버튼 없음

불필요하게 장시간 대기하는 방식보다 fake timer 등 기존 테스트 기능을 활용하세요.

### C. 아래쪽 내용 안내

사용자가 이미 기본 동작을 확인했으므로 간단한 회귀 검사만 수행하세요.

- OFF면 표시되지 않음
- ON이며 아래에 내용이 있으면 표시
- 끝까지 스크롤하면 사라짐
- 다시 위로 스크롤하면 나타남
- 메뉴 조작 및 스크롤을 방해하지 않음
- 쉬운 말과 스마트 길잡이 전환 후에도 ON/OFF 정책 유지

**스크롤 안내 로직 자체는 변경하지 마세요.**

### D. 화면 크기·배치

다음 화면 크기를 확인하세요.

- 360×667
- 390×844
- 데스크톱 브라우저

최소한 아래 조건을 검증하세요.

- 쉬운 말 ON + 자동 하단 80%
- 쉬운 말 ON + 명시적 하단 60%
- 쉬운 말 ON + 명시적 하단 70%
- 쉬운 말 ON + 명시적 하단 80%
- 스마트 길잡이 ON + 쉬운 말 ON
- 스마트 길잡이 ON + 쉬운 말 OFF

각 조건에서 다음을 확인하세요.

- 상단 안내와 하단 조작 영역 겹침 없음
- 버튼·페이지 번호·X 버튼이 실제 화면 안에 존재
- 글씨가 과도하게 축소되지 않음
- 화면 전체가 가로로 잘리지 않음
- 미리보기 내부에서 필요한 스크롤 가능
- 고대비·큰 글씨·큰 버튼 설정이 여전히 반영됨

가능하면 실제 DOM의 위치를 측정해 안내 패널과 하단 조작 영역의 교차 면적이 **0px²**인지 확인하세요.

## 6. 기존 기능 회귀 방지

다음은 변경하지 마세요.

- QR v5 프로필 스키마
- `scrollGuidance` 기본 OFF 정책
- QR 생성·조회·관리·수정 API
- 기존 QR v1~v4 호환
- AI 접근성 추천 질문과 답변 처리
- 글씨·버튼 크기 설정
- 고대비 및 언어 설정
- 단계별 안내·간결한 안내
- 스마트 길잡이 등장 지연·표시 시간 정책
- 쉬운 말의 3페이지 연습 구조
- 세로 9:16 디자인
- QR 프로필 저장값
- 개발·Production DB 구조

이번 수정은 **미리보기의 안내 배치와 그에 직접 필요한 최소한의 프런트엔드 코드·CSS**로 제한하세요.
